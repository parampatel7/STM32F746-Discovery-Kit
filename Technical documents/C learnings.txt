The fgets function reads a line from the specified stream and stores it into the string pointed to by str. It stops when either (n-1) characters are read, the newline character is read, or the end-of-file is reached, whichever comes first. The syntax for fgets is:
char *fgets(char *str, int n, FILE *stream);

The strtok() function is used to split a string into tokens (substrings) based on delimiters. It is a common task for parsing strings in C.
#include <stdio.h>
#include <string.h>

int main() {
    char str[] = "apple,banana,orange";
    char *token = strtok(str, ",");  // Split by commas
    
    while (token != NULL) {
        printf("Token: %s\n", token);
        token = strtok(NULL, ",");  // Get next token
    }

    return 0;
}
strtok() splits the string into tokens. The first call provides the string and delimiter, while subsequent calls pass NULL to continue from the last token.

It modifies the original string by replacing delimiters with \0.

C provides functions like atoi(), atof(), and itoa() (non-standard) for converting between strings and other data types.
#include <stdio.h>
#include <stdlib.h>

int main() {
    char str[] = "1234";
    int num = atoi(str);  // Converts the string to integer
    printf("Converted number: %d\n", num); // Output: 1234
    return 0;
}
int main() {
    char str[] = "3.14";
    float f = atof(str);  // Converts string to float
    printf("Converted float: %f\n", f); // Output: 3.140000
int main() {
    int num = 1234;
    char str[20];
    sprintf(str, "%d", num);  // Converts integer to string
    printf("Converted string: %s\n", str); // Output: "1234"
    return 0;    
atoi() and atof() are standard C functions, but they don’t handle errors well (e.g., if the string isn't a valid number).

sprintf() is useful for converting any data type to a string format, but be cautious of buffer overflow.

When you need to copy or move data between memory locations, including strings, C provides memcpy() and memmove(). They work on raw memory blocks, making them useful for copying strings.
memcpy(): Used to copy a block of memory from one location to another. It doesn't handle overlapping regions.
#include <stdio.h>
#include <string.h>

int main() {
    char str1[] = "Hello";
    char str2[6];
    memcpy(str2, str1, 6);  // Copies 6 bytes (including null terminator)
    printf("str2: %s\n", str2); // Output: Hello
    return 0;
}
memmove(): Similar to memcpy(), but it handles overlapping memory regions safely.
#include <stdio.h>
#include <string.h>

int main() {
    char str[] = "Hello, World!";
    memmove(str + 7, str, 6);  // Moves the first 6 characters to index 7
    printf("str: %s\n", str);  // Output: "HelloHello, World!"
    return 0;
}
